# Paper Reproduction Scripts

This directory houses turnkey scripts to regenerate experimental figures and paper artifacts in Phase 5:
- `reproduce_figure1_cdf.py`: Generates Normalized Turnaround Time & Waiting Time CDFs.
- `reproduce_figure2_pareto.py`: Generates Decision Latency vs. Mean Waiting Time trade-off frontier.
- `reproduce_figure3_heatmap.py`: Generates Memory Address Space fragmentation heatmap over time.
- `reproduce_figure4_overhead.py`: Generates Latency and Energy breakdown stacked bar charts.
